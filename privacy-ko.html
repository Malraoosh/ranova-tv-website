개인정보 처리방침

Ranova TV가 TV에 저장하는 정보, 연결하는 서비스, 그리고 정보를 삭제하는 방법을 설명합니다.

최종 수정일: 2026년 9월 30일 · English · 이 번역과 영문판이 다를 경우 영문판이 우선합니다.

이 페이지의 내용적용 범위요약TV에 저장되는 정보기기 ID제공업체와의 연결앱이 연결하는 기타 서비스백업정보 삭제고객 지원에 문의할 때이용자의 권리아동이 웹사이트방침의 변경연락처

적용 범위

이 방침은 Samsung Smart TV, LG webOS, Android TV / Google TV용 Ranova TV 앱과 이 웹사이트에 적용됩니다. Ranova TV는 요르단에 거주하는 독립 개발자 Mohammad Al Raoosh가 만들었습니다. 이용자가 연결하는 제공업체는 각자의 개인정보 처리방침을 가진 독립된 서비스입니다.

요약

  • Ranova TV 계정이나 Ranova TV 서버는 없습니다. 이용자가 입력한 정보는 TV에 저장되며, 해당 정보가 속한 제공업체와만 공유됩니다.
  • 앱에는 광고, 분석, 오류 보고 도구가 없습니다.
  • 앱은 작동을 위해 이용자의 제공업체에 연결하며, 아래에 설명된 두 가지 경우에는 다른 서비스에도 연결합니다.

TV에 저장되는 정보

앱은 다음 정보를 TV의 앱 전용 저장 공간에 보관합니다.

  • 소스: 각 소스에 붙인 이름, 재생목록 또는 서버 주소, 편성표 주소, 입력한 사용자 이름과 비밀번호.
  • 제공업체의 콘텐츠 목록: 앱을 빠르게 열 수 있도록 소스에서 내려받은 채널, 영화, 시리즈 및 편성표.
  • 내 목록과 이어보기 위치(이어보기 기능에 사용).
  • 언어, 테마, 재생 버퍼, 마지막으로 사용한 소스 등의 설정.

이 정보는 개발자에게 전송되지 않습니다. 앱은 검색 기록을 보관하지 않습니다.

로그인 정보는 앱의 전용 저장 공간에 보관되지만 암호화되지는 않습니다. TV의 앱 데이터에 접근할 수 있는 사람은 이를 읽을 수 있으므로 TV를 안전하게 관리하십시오.

기기 ID

앱은 TV 플랫폼이 제공하는 TV의 기기 식별자를 읽어 설정의 정보(About) 항목에 표시합니다. 이 식별자는 TV 안에서만 사용되며 어디로도 전송되지 않습니다.

제공업체와의 연결

소스를 추가하면 앱은 로그인, 목록과 편성표 다운로드, 이미지 불러오기, 스트림 재생을 위해 해당 제공업체에 연결합니다. 제공업체는 해당 서비스를 이용하는 다른 앱과 마찬가지로 로그인 정보, 요청 내용, TV의 IP 주소를 받습니다.

일부 제공업체는 HTTPS 대신 일반 HTTP를 사용합니다. HTTP에서는 로그인 정보와 시청 요청이 전송 중에 암호화되지 않습니다. Xtream 소스에서는 사용자 이름과 비밀번호가 요청 주소에 포함됩니다. 제공업체가 HTTPS 주소를 제공하는 경우 HTTPS 주소를 사용하십시오.

앱이 연결하는 기타 서비스

  • Lorem Picsum (picsum.photos): 홈 화면이 이 이미지 서비스에서 장식용 배경 사진을 내려받습니다. 이 요청으로 TV의 IP 주소가 해당 서비스에 전달됩니다. 이용자나 이용자의 소스에 관한 정보는 포함되지 않습니다.
  • YouTube: 제공업체가 예고편을 지정한 영화나 시리즈를 열면, 앱은 해당 예고편이 존재하는지 YouTube에 확인합니다. 이때 IP 주소와 예고편의 동영상 ID가 Google에 전달됩니다. 예고편을 선택하면 YouTube 앱이 열리며, 그곳에서는 Google의 개인정보 처리방침이 적용됩니다.

앱은 그 밖의 외부 서비스를 사용하지 않습니다. 인터넷에서 글꼴을 내려받지 않으며 추적이나 광고 서비스를 사용하지 않습니다.

백업

Android TV에서는 앱 데이터가 Google 클라우드 백업과 기기 간 전송에서 제외됩니다. Ranova TV는 어떤 플랫폼에서도 자체 백업을 만들지 않습니다.

정보 삭제

  • 소스 하나 삭제: 설정에서 소스(Sources)를 열고 삭제(Delete)를 선택하거나, 소스를 열고 소스 제거(Remove source)를 선택합니다. 그러면 해당 소스의 로그인 정보, 채널, 편성표, 내 목록 항목, 이어보기 위치가 TV에서 삭제됩니다.
  • 모두 삭제: Ranova TV를 삭제(제거)하거나 TV의 앱 설정에서 앱 데이터를 지웁니다.
  • 내 목록에서 항목 하나 삭제: 해당 작품을 열고 내 목록에 있음(In My List)을 선택합니다.

개발자는 TV에 저장된 정보에 접근할 수 없으므로 원격으로 삭제할 수 없습니다. 소스를 삭제해도 제공업체가 보유한 이용자 정보는 삭제되지 않습니다. 이를 원하면 제공업체에 문의하십시오.

고객 지원에 문의할 때

고객 지원에 이메일을 보내면 이메일 주소, 메시지, 첨부 파일을 받게 됩니다. 이 정보는 답변하는 데에만 사용합니다. 이메일은 이메일 서비스 제공업체가 처리하며, 요청을 해결하는 데 필요한 기간 동안만 보관합니다. 비밀번호, 결제 정보, 로그인 정보가 포함된 재생목록 주소는 보내지 마십시오. 언제든지 이메일 삭제를 요청할 수 있습니다.

이용자의 권리

거주 지역에 따라, 이용자는 당사가 보유한 개인정보에 대한 열람, 정정 또는 삭제를 요청할 권리를 가질 수 있습니다. 앱은 당사에 아무 정보도 보내지 않으므로, 실제로 해당되는 정보는 고객 지원 이메일뿐입니다. 요청하려면 아래 연락처로 문의하십시오.

아동

Ranova TV는 아동을 대상으로 하지 않으며, 아동의 정보를 고의로 수집하지 않습니다.

이 웹사이트

이 웹사이트에는 광고, 분석, 쿠키, 양식, 스크립트가 없으며, 글꼴과 이미지는 사이트에서 직접 제공됩니다. 이 사이트는 GitHub Pages에서 호스팅되며, GitHub는 GitHub 개인정보 보호정책에 설명된 대로 보안을 위해 방문자의 IP 주소를 기록합니다.

방침의 변경

계정, 휴대전화 연동, 동기화, 분석, 결제 기능을 추가하는 등 앱의 데이터 처리 방식이 바뀌기 전에 이 페이지를 업데이트합니다. 상단의 날짜가 현재 버전을 나타냅니다.
